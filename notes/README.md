# AI Agent 论文阅读笔记

这个目录用于保存对仓库中论文的逐篇阅读笔记。笔记按原仓库的四层分类组织：

1. `capabilities`：Agent 能做什么
2. `architecture`：Agent 如何构建
3. `operations`：Agent 如何运行、交互与治理
4. `applications`：Agent 应用在哪些场景

## 使用方式

每开始一篇新论文，复制 [`TEMPLATE.md`](TEMPLATE.md)，按“分类/年份-简称”命名，并在上方的进度表中添加链接。
